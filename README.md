## 🚀 快速开始

### 本地开发
```bash
# 安装Jekyll (如果需要本地预览)
gem install bundler jekyll

# 克隆项目
git clone git@github.com:yourusername/huaningmou-website.git
cd huaningmou-website

# 本地运行
bundle exec jekyll serve
# 访问 http://localhost:4000
```

### 部署到GitHub Pages
1. 推送代码到GitHub仓库
2. 在仓库设置中启用GitHub Pages
3. 选择分支 (通常为main或gh-pages)
4. 访问 https://yourusername.github.io/huaningmou-website
